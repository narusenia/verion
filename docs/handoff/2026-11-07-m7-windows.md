# 引き継ぎ: M7 の Windows 確認（Vulkan）

Mac（Metal）で M7 の作業は終わった。Windows（RTX 3080、Vulkan）で確認が要るのは、共通のコードを変えた部分だけ。NRC の本体は Metal だけで、Vulkan には入れていない（2026-11-07 に利用者が決定）。状態の正本は `docs/implementation/M7-nrc-adaptive-integrator/README.md` の表。画像アルファの確認は `2026-11-07-alpha-cutout-windows.md` に手順があり、この文書の手順 3 で一緒に回す。

## Vulkan に影響した変更
- `PARAM_WORDS` が 49 から 81 になった。語 43 は seed、44〜48 は NRC の設定、49〜80 はタイルごとのフォールバックのビット。Vulkan のパラメータバッファはこの幅で組まれるので、サイズが増えただけで挙動は変わらないはず（`restir` の語は変えていない）
- SPIR-V を再生成してコミット済み（`pathtrace.spv`、`wf_shade.spv`、新規の `nrc_validate.spv` ほか）。Mac で生成した。`mise run shaders:check` が Windows で通ること
- NRC のパラメータはバインディング 19（ReSTIR の `restir`）を共用する。Vulkan のレイアウトは変えていない。シェーダーの `nrcCompiled` は特殊化定数だが、Vulkan のホストは常に偽で渡す
- Vulkan で NRC を求めると `set_nrc(Some)` がエラーを返す。`render-cli --nrc` と Python の `nrc={}` はエラーで終わり、Viewer は警告を出してスイッチを戻す。これが期待どおりの動き
- Python と Blender の NRC のテストは、macOS 限定にしてある（`test_render.py`、`plugins/blender/tests/test_final.py`）
- `--seed` が入った。画素の乱数に seed を混ぜるので、同じ seed なら Metal と Vulkan の画像一致の比較に使える

## Windows でやること
1. `mise run check`、`mise run shaders:check`、`mise run test:gpu`
2. `sh scripts/blender_test.sh`（Blender 4.5 と 5.2）と、Python のテスト（`mise run test:py`）。NRC のテストは飛ばされる
3. 画像アルファ（A5）の Vulkan の画像一致: `2026-11-07-alpha-cutout-windows.md` の手順 2〜3。`test_consistency.py` の `blender.exr` を Mac の値（平均の比 1.0000、ブロック相関 1.00000）と並べる。Metal と Vulkan を直接比べるなら `scripts/backend_diff.sh`
4. 退行の確認: `scripts/bench.sh` か `render-cli` の `gpu_s` を、`PARAM_WORDS` 変更前（`7a0ccfa`）と並べる。見るのは cornell_box と many_lights（512×384、128 spp）。Mac の Metal では、アルファ対応で約 2% の増加があり、許容と決めてある（特殊化定数で消すとパイプラインが両 Backend で倍になるため）。Vulkan が 5% を超えて遅くなっていたときだけ、見直す
5. 結果を次に書く: `docs/implementation/M6-blender/consistency.md`、M7 README の A5 の行と完了条件の最初の項目

## 持ち越し
- Octane との同画質到達時間の比較（M5 から。REQ-ACC-002）は、Blender 連携の後で、実機の Octane が要る
- NRC の Vulkan での速度の実験（作るかの判断材料）は `2026-11-07-nrc-vulkan-spike.md` に切り出した
- NRC の Vulkan 版は作らない。ADR-0022 に結果と決定がある。再開するなら、`nrc_*.slang` と `nrc_net.slang` は Slang のままなので、ホスト側（パイプライン 4 本と Buffer、`set_nrc`、検証の dispatch）を `crates/verion-gpu-vulkan` に足す
