## MORT のスパイクの結果（M7 に効く部分）
- Oracle L0（グリッドの入射放射輝度。SH L2 と八面体 8×8）で、不偏の MORT は同じ GPU 時間あたり plain の 0.25〜0.69 倍（球あり）、0.42 倍（拡散のみ）。S1 の基準（4 倍）に届かない。NRC を MORT の L0 にして不偏にする案は採らない
- 1 次ヒットで切って `Le + NEE + L0` だけで描く偏りのある版は、拡散のみの Cornell で plain の約 6 倍の効率（Oracle の焼き込み 4.5 s は含めない、L0 の偏りは約 1%、1 seed）。NRC の評価（M7 の 8）の上限の目安
- DELTA は M7 の外。ArcheRender（`~/ghq/github.com/NaruseNia/arche-render`、MORT と DELTA は機能化トラック）の CPU 実験が基準を通ってから、別のマイルストーンで計画する
- 流用できるもの（スパイクのブランチ）: `crates/verion-gpu-metal/examples/mort_spike.rs`（relMSE と平均の比を、高 spp の参照との比較で出す。参照は `Renderer::set_sample_base` で別の乱数列にして、相関を避けている）、`shaders/mort_bake.slang`（グリッド点から高 spp で焼く）

## 決定済み（変えるときは利用者に確認）
- NRC のネットワーク実行は Slang の自前カーネル（ハッシュ符号化＋小型 MLP）を先にする。CUDA や Tensor は、学習が律速と測定で分かったときだけ
- NRC は選択式で既定は無効、Reference モードは通らない、有効なら非物理の印。評価で学習込みの利益が出なければ、無効のまま結果を記録して終える
- まず間接の拡散だけを置き換え、Lighting AOV の成分分離を壊さない。鏡面・コースティクス・屈折・編集直後は物理 PT のまま
- glTF の仮想主光源の上書き項目は見送り。ADR-0018 の追記は承認済み

## 次の一手
