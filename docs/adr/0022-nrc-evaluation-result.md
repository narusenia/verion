# ADR-0022: NRC の評価結果（Metal）。既定は無効のまま、Vulkan 以降は利用者の判断を待つ

- 状態: 採用（M7 項目 3〜8 の結果。続けるかの基準は仮置きで、利用者の確認を待つ）
- 日付: 2026-11-07

## 背景

ADR-0021 の基準（`scripts/eval_nrc.sh`、16 seed、95% 信頼区間、Apple M4 Pro・AC 電源、512×384、参照 16384 spp）に、NRC を同じ手順で足して測った。

## 実装したもの（Metal、Megakernel と Wavefront）

- キャッシュするもの: 深さ 1 の拡散ヒット q での、間接の入射放射輝度（E/π）。積分器は、最初のバウンスが拡散で、q が拡散だけの面（金属・透過・コート・シーンなし）のとき、経路を q で切り、`thr × albedo × (1 − F) × C(q)` を加える。q の直接光は既存の光源サンプリング（MIS 重み 1）が受け持つ。鏡面・屈折・コースティクスは物理 PT のまま。無効のとき `nrcCompiled`（特殊化定数）でカーネルから消える
- 学習: 専用カーネル `nrc_collect` が、画素 → 拡散バウンスで q → さらに 4 バウンス、と追跡し、各頂点で光源サンプリングを足して、末端でキャッシュを引く（自己学習）。1 バウンスで切ると、反射率が高い閉じた部屋で誤差が増幅される（`1/(1−ρ)`）ため、4 バウンスに展開した。1 サンプルあたり 1 ステップ、バッチ 16384、ウォームアップ 128 ステップ（学習時間に含める）
- 編集: キャッシュは捨てて学習し直す（ADR-0017 の「捨てる」）。Cornell 相当の部屋で壁の色を変えると、床の間接光が赤くなり、物理 PT との差は 10% 以内（`tests/update.rs`）。継続学習で追従する案は測っていない
- 出力: `--mode interactive --nrc`（ReSTIR は置き換える）。Reference モードは拒否する。EXR に `verion/nrc`、metrics に `train_s`・`nrc_bytes`。ネットワークと勾配と Adam の状態は約 9.2 MB（8.4 MB＋バッチ）

## 結果（同画質到達時間: 物理 PT の 128 spp と同じ誤差になるまで。学習時間込み）

| シーン | ReSTIR GI | NRC |
|---|---|---|
| cornell_box | 2.26 倍 | 1.08 倍 |
| cornell_diffuse | 1.78 倍 | 1.28 倍 |
| indoor | 1.66 倍 | 2.15 倍 |
| many_lights | 3.87 倍 | 基準に届かない（偏りが残る） |

NRC が ReSTIR GI を上回るのは、間接光が支配的で経路が長い `indoor` だけ。ほかは ReSTIR GI のほうが速い。`many_lights` は直接光が支配的で、NRC は偏りが 128 spp でも物理 PT の誤差を下回れなかった。

## 決定

- NRC は既定で無効のまま、選択式の機能として残す（`--nrc`）。汎用の高速化としては勧めない。間接光が支配的で経路の長いシーンに限って効く
- ADR-0021 の仮の基準（2 倍以上）では、4 シーン中 1 つしか通らない。項目 8 の「基準を満たさなければ 9 以降は行わない」に従い、Vulkan 版（項目 9）、ReSTIR PT の判断（10）、Adaptive Integrator（11・12）、UI のスイッチ（13）には進んでいない。基準の数値と進めるかは利用者が決める
- 項目 5 の学習した信頼度による領域ごとのフォールバックは作っていない。静的な適格条件（金属・透過・コート・シーンの面は使わない）だけが入っている。評価が基準を通らない以上、信頼度の仕組みを足す根拠がまだない
- Vulkan では `set_nrc(Some)` がエラーを返す（未実装を明示）
